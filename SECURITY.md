# MOSAG – Sicherheits- und Freigabecheckliste

- [ ] Repository bleibt privat; nur notwendige Zugriffsrechte für Integrationen.
- [ ] GitHub-Konto mit 2FA absichern.
- [ ] Keine API-Schlüssel, Tokens, Passwörter oder Kundendaten in Git committen.
- [ ] `npm install`, `npm run build`, Dependency-Audit vor jedem Release.
- [ ] HTTPS und sichere Domain-Konfiguration prüfen.
- [ ] Sicherheitsheader nach Deployment mit echten HTTP-Antworten überprüfen.
- [ ] Kontaktformular nur mit funktionierender serverseitiger Verarbeitung veröffentlichen.
- [ ] Formulareingaben serverseitig validieren, Spam-Schutz und Rate Limits konfigurieren.
- [ ] Formularbenachrichtigungen, Fehlerfälle und Zustellung testen.
- [ ] Datenschutz und Auftragsverarbeitung des Hosters/Formularanbieters klären.
- [ ] Datenschutzerklärung und Impressum vor Livegang rechtlich prüfen.
- [ ] Backups und Wiederherstellungsverfahren dokumentieren.
- [ ] Keine unnötigen Tracking-Skripte oder Drittanbieterressourcen hinzufügen.
- [ ] Domaininhaberschaft und Markennutzung vor Registrierung prüfen.
